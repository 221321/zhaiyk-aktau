# Деплой

После мержа изменений в `main` — на сервере:

```bash
cd /var/www/zhaiyk-aktau && git pull && npm install --omit=dev && pm2 restart zhaiyk-aktau
```

Бэкап (`npm run backup`, см. `scripts/backup-db.sh`) в этот шаг намеренно
не входит — при частых деплоях он быстро копит копии `db.json`/`uploads/`
и забивает диск сервера. Регулярный бэкап живёт отдельно, на ежедневном
cron (`0 3 * * * cd /var/www/zhaiyk-aktau && ./scripts/backup-db.sh >> backups/backup.log 2>&1`,
30-дневная ротация) — этого достаточно; перед конкретным рискованным
деплоем бэкап можно снять вручную (`npm run backup`) по своему усмотрению.

`npm install --omit=dev` нужен, если менялись зависимости в `package.json`
(на случай, если пропустить — обычно не страшно, но лучше выполнять каждый раз).
Процесс в pm2 называется `zhaiyk-aktau`.

Перед мержем в `main` стоит прогнать `npm test` (см. `TESTING.md`) — ловит
часть регрессий на деньгах/остатке до того, как они попадут на прод.
